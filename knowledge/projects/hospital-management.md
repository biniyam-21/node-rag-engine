# HSIM Dashboard

Information management dashboard built with a modern TypeScript stack.

## Overview

HSIM Dashboard is a data-focused dashboard application with data tables, filtering, and role-aware views. It demonstrates Biniyam's ability to build structured admin interfaces with clean UX.

## Features

- Data tables with sorting and filtering
- Role-aware views for different user types
- Modern TypeScript and React architecture
- Dashboard layout optimized for information density

## Tech Stack

TypeScript, React, Dashboard UI patterns

## Role

Full-stack / frontend development — designed and implemented the dashboard interface and data views.

## Related Context

Also referred to in the knowledge base as a hospital/information management system project. It focuses on presenting structured data clearly for operational users.
