# Droga Pharma Redesign

Accessibility-first redesign of a real pharmaceutical company's website.

## Overview

Biniyam rebuilt a pharmaceutical company's web presence with a focus on accessibility, user experience, and a clean professional visual language. The project demonstrates front-end craft applied to a live business context.

## Impact

- Accessibility-first rebuild of a live company site
- Improved visual hierarchy and professional presentation
- Responsive layout for mobile and desktop users

## Tech Stack

HTML, CSS, JavaScript, UX design principles

## Focus Areas

- Accessibility (semantic HTML, readable contrast, keyboard-friendly navigation)
- Clean, professional visual design for a pharmaceutical brand
- Responsive layouts across screen sizes

## Role

Solo frontend developer — handled design direction, implementation, and UX improvements.
