# This Portfolio

Dashboard-style portfolio site with interactive UI and an AI assistant widget.

## Overview

The portfolio site Biniyam built to showcase his work — designed as a dashboard rather than a traditional landing page. It includes a command palette, AI-style assistant, terminal widgets, and GSAP micro-interactions.

## Impact

- Command palette for quick navigation
- AI assistant widget for answering questions about his work
- Custom design system with polished micro-interactions
- Dashboard-style layout inspired by developer tools

## Tech Stack

React, Vite, Tailwind CSS, GSAP, Framer Motion

## Features

- Interactive dashboard navigation
- Terminal-style widgets
- GSAP and Framer Motion animations
- Responsive design across devices
- Ask About Me page powered by RAG-style Q&A

## Role

Solo designer and developer — full ownership of UI, interactions, and frontend architecture.
