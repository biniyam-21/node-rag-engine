# Di-Assist

Healthcare drug information platform for clinicians — a solo full-stack build.

## Overview

Di-Assist helps clinicians access drug information quickly. It includes an AI-powered assistant, drug interaction checker, analytics dashboard, and user management.

## Impact

- AI assistant for drug information queries
- Drug interaction checker for safer prescribing decisions
- Clinician analytics dashboard
- User management and authentication

## Tech Stack

Next.js, React 19, Tailwind CSS v4, Prisma, Better Auth, Gemini AI, PostgreSQL

## Status

Beta (~80% progress)

## Role

Solo full-stack developer — designed and built the entire platform independently.

## Key Features

- AI-powered drug information assistant
- Drug interaction checking
- Analytics dashboard for usage insights
- Role-based user management with Better Auth
